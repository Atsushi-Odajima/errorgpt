注意事項

1. 保証しないこと
　報告が必ず修正される、開発元に必ず読まれる、AI の精度向上に必ず使われる、ということは保証しません。

2. 自動送信について
　OpenAI サポート、Codex の /feedback には自動送信できません。ErrorRelay は準備までを行い、送信はあなたが公式窓口で行います。「送信済み」と表示されるのは、公式の送信 API から受付番号を受け取れた場合だけです。

3. 個人情報
　自動検出は完全ではありません。送る前に必ず自分の目で確認してください。パスワード・認証コード・API キーは送らないでください。

4. 原因について
　ErrorRelay はエラーの原因を断定しません。「症状の報告」を作ります。

5. 公式窓口の変更
　OpenAI の窓口や仕様は変わることがあります。報告先の情報には「確認日」が表示されます。古い場合は運用者に更新を依頼するか、公式サイトを直接確認してください。

6. データの保存
　「この端末だけ」モードではブラウザ内にだけ保存されます。サーバーモードでは運用者のサーバーに保存され、既定で 30 日後に自動削除されます（PRIVACY.md）。

7. 脆弱性の報告
　ErrorRelay 自体の脆弱性は公開の場ではなく、販売元のサポート窓口へ連絡してください。

8. 対応環境
　Windows / macOS / iPhone / Android の最新ブラウザ。Codex CLI/Desktop、ChatGPT Plugin（MCP）。実機での動作は環境により異なります。
