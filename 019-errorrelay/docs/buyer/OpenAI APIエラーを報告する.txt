OpenAI API エラーを報告する

集める情報
・request ID（レスポンスヘッダー x-request-id、または「req_」で始まる ID）← サポートが最も必要とする情報です
・エンドポイント（/v1/responses など）、HTTP ステータス、error type / code、発生時刻
・SDK と言語・バージョン（例：openai-python 1.60.0）
・地域・ネットワーク（分かる範囲）
・最小の再現コード

ErrorRelay での手順
1. 「エラー文から報告を作る」で、SDK の例外メッセージやレスポンス JSON を貼り付けます。
   → request ID、ステータス、エンドポイントが自動で抜き出されます（見つからないときは空欄のままです）。
2. 「設定」→「OpenAI API」欄に貼り付けると、解析結果と再現用 curl（API キーは $OPENAI_API_KEY のプレースホルダー）が出ます。
3. 秘密情報をスキャン → API キーは必ずマスクされます。request ID はサポートに必要なので残ります。
4. 報告形式「developer」を選ぶと開発者向けの体裁になります。
5. 公式窓口（ヘルプセンター）へ手渡し、または書き出し。

注意
・API キーやリクエスト本文全体を添付しないでください。必要な部分だけを、マスクしてから。
・再現コードにも本物のキーを入れないでください。
