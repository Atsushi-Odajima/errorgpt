ErrorRelay — AIエラー報告アシスタント　はじめに

ErrorRelay は、ChatGPT や Codex、OpenAI API で出たエラーを
「開発元に伝わるバグ報告」にまとめるツールです。

できること
・スクリーンショットやエラー文から、報告に必要な情報（いつ・どの製品・どの環境・何をしたら・本来どうなるはず・実際どうなった）を整理します。
・メールアドレス・電話番号・APIキー・パスワードなどを自動で見つけてマスクします（完全ではないので最後は自分で確認してください）。
・日本語と英語の報告文を作り、TXT / Markdown / JSON / ZIP に保存できます。
・OpenAI の公式窓口（ヘルプセンター、Codex の /feedback、GitHub Issue）へ「準備した内容」を持っていけます。

できないこと・保証しないこと
・OpenAI サポートへの自動送信はできません（公開された送信 API が無いためです）。最後の送信はあなた自身が公式窓口で行います。
・報告が必ず修正される、必ず開発元に読まれる、AI の改善に使われる、といった保証はありません。
・エラーの原因を断定しません。ErrorRelay が作るのは「症状の報告」です。

3 ステップ
1. 証拠を追加（スクショ／エラー文／発生した時刻）
2. AI が整理（再現手順・期待/実際・環境・マスク）
3. 確認して報告（プレビュー → 公式窓口へ手渡し、または書き出し）
