「送信」と「Handoff（手渡し）」の違い

ErrorRelay は報告先ごとに「どうやって届けられるか」を表示します。

DIRECT（送信）
　公式に公開された送信 API がある場合だけ。最終確認画面で「送信する」を押すと ErrorRelay が送り、受付番号（receipt）を受け取れたときだけ「送信済み」と表示します。
　2026-09-30 時点で OpenAI サポートと Codex /feedback は DIRECT ではありません。

INTERACTIVE_HANDOFF（手渡し）
　ErrorRelay が本文と添付を準備し、公式窓口を開きます。貼り付けて送るのはあなたです。
　状態は「公式窓口へ手渡し準備済み」→ あなたが「自分で送信した」を押すと「利用者が送信済みと記録」になります（システムが確認した「送信済み」とは区別されます）。

EXPORT_ONLY（書き出し）
　TXT / Markdown / JSON / ZIP に保存するだけ。送信はしません。

UNAVAILABLE
　現在使えない報告先。

どの場合も、最終確認画面（送信先・本文・添付・マスク状況・相手に見える身元）を見てからでないと先に進めません。同じ報告を何度も送らないよう、再送時は二重送信を防ぎます。
